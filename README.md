# Último Refugio VR (Eixample, Barcelona)

Survival zombi en WebXR para Meta Quest 3. Se juega abriendo la página de GitHub Pages en el navegador de las gafas.

- `index.html` + `game.js`: el juego (game.js se genera con `python3 build.py` a partir de `src/`).
- `src/`: código fuente por módulos (núcleo, calles, fachadas, interiores, puertas, bases, personajes, jugador, juego).
- `lib/`: three.js r160 (MIT).
- `assets/tex`: texturas CC0 de Poly Haven y ambientCG (grafitis y hojas) + panot/granito generados.
- `assets/models`: personajes y manos de los ejemplos de three.js y de webxr-input-profiles (MIT).
- `assets/snd`: gemidos zombi CC0 de OpenGameArt.
